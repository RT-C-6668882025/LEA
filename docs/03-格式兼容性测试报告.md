## 五、已知限制

1. Markdown 内的**本地相对路径图片**暂不显示（离线沙箱策略）；远程图片同样不加载。
2. MP4/WebM 依赖 Electron 内置编解码器（H.264/AAC/VP9/AV1(部分)/Opus）；HEVC 不支持。
3. PDF.js 以主线程/Worker 混合模式渲染，超大 PDF（>500 页）滚动渲染可能掉帧。
4. 沙箱 HTML 不能引用外部 CDN 资源（设计如此；交互演示请使用内联脚本/样式）。
5. 未签名安装包触发 SmartScreen 提示；UR L拉取不做 DNS 级内网探测（仅主机名与重定向校验）。

## 六、豆包桌面版兼容性

- MCP Server 为标准 stdio JSON-RPC（2024-11-05），initialize 回显客户端 protocolVersion，兼容主流客户端。
- 豆包桌面版入口为「技能·连接器·伙伴 → 新建自定义连接器 → 本地命令」，添加 mcp-server.exe 后需"信任+启用"。
- 最终连接需在有豆包桌面版的机器上按 docs/02 执行人工验收（本报告覆盖协议与端到端链路的自动化验证）。
