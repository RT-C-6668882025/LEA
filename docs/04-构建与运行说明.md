# 构建与运行说明

## 环境要求（构建机）

- Windows 10/11 x64
- Node.js ≥ 18（开发用 Node 24 验证）
- npm（首次构建需联网下载依赖与 Electron 二进制；最终产物离线运行）

## 首次构建

```bash
npm install          # 安装依赖（含 Electron 33、electron-builder、Tiptap 等）
npm run fixtures     # 生成测试夹具（md/pdf/png/wav/mp4 + page-demo 可编辑页面）
npm run icon         # 生成 build/icon.ico 与 icon.png
npm run build:editor # 打包 Tiptap 依赖 → src/renderer/editor.bundle.js（npm run dist 已自动包含）
npm run build:mcpexe # 构建 SEA 版 mcp-server.exe（Node 单可执行应用）
npm run dist         # = build:editor + build:mcpexe + NSIS 打包 → dist/LEA-Setup-0.2.0.exe
```

## 开发运行

```bash
npm start            # 启动 GUI 客户端；可附带文件: npm start -- test/fixtures/sample.pdf
npm run mcp          # 以纯 Node 运行 MCP stdio Server（配合 GUI 客户端）
npm run test:mcp     # MCP 端到端冒烟测试（30 项断言，会自动拉起客户端）
node test/mcp-probe.mjs node src/main/mcp-stdio.js   # 单探针
```

## 安装包内容

```
LEA.exe          GUI 客户端（含 --mcp-stdio 检测：Windows 上会弹窗指引，见下）
mcp-server.exe                 独立 MCP Server（推荐，Node SEA）
resources/app/                 应用代码（asar 关闭，含 mcp-server.cmd 备选启动器）
```

> **为什么是 mcp-server.exe？** Electron 的 GUI 主进程在 Windows 上 stdio 不可用
> （stdin 立即 EOF、stdout 失联），因此 `LEA.exe --mcp-stdio` 无法充当
> stdio 服务器，运行时会弹窗说明并退出；`mcp-server.exe` 由 Node SEA 生成，属于控制台
> 子系统，stdio 对所有 MCP 客户端可靠。它通过 Windows 命名管道
> `\\.\pipe\lea-ipc` 与 GUI 客户端通信，客户端未运行时自动拉起。

## 已知构建注意点

- `asar` 关闭（PDF.js worker 与 .cmd 备选启动器需要真实文件路径）
- electron-builder 需下载 NSIS；网络受限时设置
  `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`
  与 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`
- 安装包未做代码签名：首次运行会有 SmartScreen 提示，选「仍要运行」即可
- `pdfjs-dist` 锁定 3.11.174（UMD 构建，免打包器直接 <script> 引入）
